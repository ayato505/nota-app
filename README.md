# نوتة (NŌTA)

مكتبة مذاكرة الدفعة: المواد والمحاضرات والملخصات والجروبات في مكان واحد.

## تحميل التطبيق (أندرويد)

**[⬇️ تحميل نوتة](https://github.com/ayato505/nota-app/releases/latest/download/nota.apk)**

1. حمّل الملف من الرابط اللي فوق.
2. افتحه من الموبايل. لو ظهرت رسالة "تثبيت من مصادر غير معروفة"، اسمح بيها للتطبيق اللي فتحت منه الملف.
3. افتح نوتة وادخل بحساب Google.
